Built for the actual problem

Nothing magical. Nothing in chat.

SecretBridge does not pretend a local .env file is Fort Knox. It prevents the easy, permanent mistake: placing a reusable credential in an AI conversation or tool transcript.

  • Native masked entryThe value never becomes an MCP argument.
  • Reusable credentialsAsk for the same labeled secret in future sessions.
  • Explicit completion receiptThe AI knows when you clicked save and can continue.
  • Workspace-scoped writesEvery destination and variable mapping is shown for approval.
  • Local-only designNo hosted service, account, analytics, or network listener.

Source-first installation

Install on Mac or Windows.

Rust builds the executable locally, avoiding warnings for unsigned downloaded applications.

●

macOS

Apple Silicon or Intel

git clone https://github.com/Abomination81/secret-bridge-mcp.git
cd secret-bridge-mcp
./scripts/install.sh

Installs to ~/.local/bin/secret-bridge-mcp.

⊞

Windows

PowerShell on Windows 11

git clone https://github.com/Abomination81/secret-bridge-mcp.git
cd secret-bridge-mcp
.\scripts\install.ps1

Installs under %LOCALAPPDATA%\SecretBridge.

Requires the free Rust toolchain. Tagged GitHub releases also include unsigned convenience archives and SHA-256 checksums.

Works where local MCP works

Connect your AI client.

Codex

codex mcp add secret-bridge -- \
  /absolute/path/secret-bridge-mcp \
  --workspace-root /path/to/project \
  --client-name Codex

Claude Code

claude mcp add --scope user \
  --transport stdio secret-bridge -- \
  /absolute/path/secret-bridge-mcp \
  --workspace-root /path/to/project \
  --client-name "Claude Code"

Also works with Gemini CLI and other local MCP clients that can launch a standard-input/output server. Full configuration examples are in the README.

!

The honest boundary

Out of the conversation—not invisible on disk.

SecretBridge keeps values out of AI messages, MCP payloads, logs, and command history during collection and reuse. Once you approve an .env write, that file is normal local plaintext and can be read by software with filesystem access.
