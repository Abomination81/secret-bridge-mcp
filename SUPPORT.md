# Support

Use [GitHub Issues](https://github.com/abomination81/secret-bridge-mcp/issues) for installation help, compatibility reports, and ordinary bugs.

Include the SecretBridge version, operating system, AI client, and the exact non-secret error message. Never include a credential, `.env` contents, Keychain export, Credential Manager export, or secret-bearing screenshot.

Report security vulnerabilities privately using the process in [SECURITY.md](SECURITY.md).
